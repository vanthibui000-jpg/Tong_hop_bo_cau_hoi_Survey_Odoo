ODOO QUIZ - MEMBERS

1. Mở folder bằng VS Code.
2. Chạy index.html bằng Live Server.
3. Thành viên nhập họ tên.
4. Chỉ kết quả đạt trên 80% và đủ điều kiện nhận chứng nhận mới được lưu bằng localStorage.
5. Nếu bài có đầy đủ answer key và điểm > 80%, nút "Xem phiếu khen thưởng" xuất hiện.
6. Nhấn "In / Lưu PDF" để in hoặc Save as PDF.

LƯU Ý:
- Đây là phiên bản frontend-only.
- localStorage KHÔNG đồng bộ giữa nhiều máy/điện thoại.
- Nếu muốn tất cả thành viên ở các thiết bị khác nhau cùng lưu vào một danh sách chung,
  cần thêm backend/database (ví dụ Firebase, Supabase, MySQL, SQL Server...).
